HBASE USE CASE 3 — CUSTOMER 360 / CUSTOMER PROFILE
==================================================

Project: Customer 360 / Customer Profile

Environment: Ubuntu / WSL

Technologies: HBase + HDFS + Hadoop


------------------------------------------------
1. PROJECT OBJECTIVE
------------------------------------------------

A telecom company has millions of customers and needs very fast access to customer information.

The system stores:

Customer ID
Customer Name
City
Mobile Number
Plan
Status
Data Usage

HBase is suitable because Customer ID is used as the RowKey, allowing fast lookup of an individual customer.

Expected operations:

Create HBase table
Insert customer data
Update customer data
Retrieve one customer
Retrieve multiple customers
Delete a column
Delete a customer
Count customers
Describe table
Disable table
Drop table


------------------------------------------------
2. REQUIRED COMPONENTS
------------------------------------------------

HBase       -> NoSQL database
HDFS        -> Storage layer
Hadoop      -> Distributed storage/framework
HBase Shell -> Execute HBase commands
Java        -> Required by HBase


------------------------------------------------
3. START HADOOP SERVICES
------------------------------------------------

Start HDFS:

start-dfs.sh

Start YARN:

start-yarn.sh

NameNode

ResourceManager
NodeManager


------------------------------------------------
4. START HBASE
------------------------------------------------

Start HBase:

start-hbase.sh

HRegionServer

30. HBASE COMMANDS USED
------------------------------------------------

create
    -> Create table

put
    -> Insert / update data

get
    -> Read one row

scan
    -> Read multiple rows

delete
    -> Delete a column

deleteall
    -> Delete a row

count
    -> Count rows

describe
    -> Display table metadata

disable
    -> Disable table

drop
    -> Remove table

32. INTERVIEW EXPLANATION
------------------------------------------------

"I implemented a Customer 360 use case using HBase for a telecom company.

I created a customer_profiles table with Customer ID as the RowKey and stored personal, subscription, and usage information in separate column families.

I used put to insert and update customer information, get for fast individual customer lookup, scan for retrieving multiple customers, and delete and deleteall for removing data.

I also used count, describe, disable, and drop to manage the HBase table."
