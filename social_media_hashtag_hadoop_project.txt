SOCIAL MEDIA HASHTAG COUNT — HADOOP STREAMING
================================================

Project: Hashtag Frequency Counter
Environment: Ubuntu / WSL
Technologies: Python + Hadoop MapReduce + HDFS + YARN + Hadoop Streaming

------------------------------------------------
1. PROJECT OBJECTIVE
------------------------------------------------

Read social-media posts from HDFS, extract hashtags using a Python Mapper,
count hashtag frequencies using MapReduce, and store the final result in HDFS.

Expected output:

7. CREATE PYTHON MAPPER
------------------------------------------------

nano mapper.py

Code:

#!/usr/bin/env python3

import sys
import re

for line in sys.stdin:
    line = line.strip()

    hashtags = re.findall(r'#\w+', line)

    for hashtag in hashtags:
        print(f"{hashtag}\t1")

Test:

cat social_posts.txt | python3 mapper.py


------------------------------------------------
8. CREATE PYTHON COMBINER
------------------------------------------------

nano combiner.py

Code:

#!/usr/bin/env python3

import sys

current_hashtag = None
current_count = 0

for line in sys.stdin:
    line = line.strip()

    if not line:
        continue

    hashtag, count = line.split("\t")
    count = int(count)

    if current_hashtag == hashtag:
        current_count += count
    else:
        if current_hashtag is not None:
            print(f"{current_hashtag}\t{current_count}")

        current_hashtag = hashtag
        current_count = count

if current_hashtag is not None:
    print(f"{current_hashtag}\t{current_count}")


Test:

cat social_posts.txt | python3 mapper.py | sort | python3 combiner.py

12. IMPORTANT — CORRECTED HADOOP STREAMING COMMAND
------------------------------------------------

Use the following command.

Then run:

hadoop jar /home/shikhasara/hadoop/share/hadoop/tools/lib/hadoop-streaming-3.3.6.jar \
-input /social_media/input \
-output /social_media/output \
-mapper mapper.py \
-combiner combiner.py \
-reducer reducer.py \
-files mapper.py,combiner.py,reducer.py


IMPORTANT:
Use -files ONCE with all three Python files separated by commas.

This is the cleaned-up version of the Streaming command.


------------------------------------------------
13. WHY -FILES IS USED
------------------------------------------------

-files tells Hadoop to make the local Python programs available to the
MapReduce tasks running in the Hadoop environment.

The three files are:

mapper.py
combiner.py
reducer.py

------------------------------------------------
16. INTERVIEW EXPLANATION
------------------------------------------------

"I implemented a hashtag frequency counter using Hadoop Streaming.
The social-media posts were stored in HDFS. A Python Mapper extracted
hashtags and generated (hashtag, 1) key-value pairs. A Combiner performed
local aggregation to reduce intermediate network traffic. Hadoop's
default Partitioner distributed keys among reducers, and Shuffle and Sort
grouped identical hashtags. Finally, a Python Reducer calculated the
total frequency and stored the final result in HDFS."
