 Section 1: Big Data fundamentals and ecosystem

# Q1. A company collects website clicks, images, application logs, and customer transactions. Which Big Data characteristic describes the diversity of these formats?

A. Volume B. Velocity C. Variety D. Veracity

Correct answer: C. Variety

Explanation: Variety refers to different data formats, including structured tables, semi-structured JSON and XML, and unstructured images, videos and text.

# Q2. An organization must store 100 TB of historical data and run distributed batch processing across multiple machines. Which traditional Hadoop combination best fits this requirement?

A. HDFS and MapReduce B. MySQL on one laptop C. Redis and browser storage D. HTML and CSS

Correct answer: A. HDFS and MapReduce

Explanation: HDFS distributes large files across cluster nodes, while MapReduce performs parallel batch processing. Modern platforms frequently use Spark for many batch workloads.

# Q3. Which statement correctly describes the core Hadoop components?

A. HDFS manages cluster resources, while YARN stores file blocks. B. HDFS stores distributed data, YARN manages cluster resources, and MapReduce executes distributed batch jobs. C. Hive manages Kafka partitions and offsets. D. MapReduce replaces the filesystem and resource manager.

Correct answer: B. HDFS, YARN and MapReduce have distinct roles.

Explanation: HDFS provides distributed storage, YARN manages computing resources, and MapReduce performs distributed batch computation.

# Q4. A research organization wants datasets to remain discoverable and reusable years after collection. Which practice is most appropriate?

A. Delete dataset descriptions after ingestion. B. Retain only the newest copy of every dataset. C. Store files without documenting their source. D. Maintain metadata, provenance, ownership, access policies and data quality information.

Correct answer: D. Maintain metadata and data curation.

Explanation: Data curation preserves a dataset's origin, meaning, quality and usability throughout its lifecycle.

 Section 2: Hadoop, HDFS and architecture

# Q5. What is the primary responsibility of the HDFS NameNode?

A. Execute every Spark task B. Maintain filesystem namespace and metadata, including file-to-block mappings C. Store every file's complete contents on its local disk D. Consume Kafka messages

Correct answer: B. Maintain filesystem metadata.

Explanation: DataNodes store the actual HDFS blocks. The NameNode manages namespace information, permissions and block-location metadata.

# Q6. An HDFS file is 256 MB, and the block size is 128 MB. Ignoring special file-layout considerations, how many logical HDFS blocks are required?

A. 1 B. 3 C. 2 D. 128

Correct answer: C. 2

Explanation: Two blocks of 128 MB each are required. Replication creates additional physical copies but does not change the number of logical blocks.

# Q7. An HDFS cluster has a replication factor of 3. One DataNode storing a block replica fails. What should happen?

A. All copies of the file are immediately deleted. B. HDFS uses surviving replicas and can schedule re-replication to restore the configured factor. C. The file is automatically converted into a Hive table. D. The file must always be permanently lost.

Correct answer: B. Use surviving replicas and restore replication.

Explanation: If sufficient healthy replicas remain, HDFS can continue serving reads and schedule new replicas to restore the desired replication factor.

# Q8. What is the primary purpose of YARN?

A. Manage cluster resources and coordinate application execution B. Replace HDFS file permissions C. Store Hive table rows D. Maintain Kafka consumer offsets

Correct answer: A. Manage cluster resources and coordinate application execution.

Explanation: The ResourceManager manages cluster resources, NodeManagers manage resources on individual nodes, and an ApplicationMaster coordinates an application.

# Q9. A local file named `events.csv` must be uploaded to the HDFS directory `/data/raw`. Which command is correct?

A. `hdfs dfs -cat events.csv /data/raw` B. `hdfs dfs -rm events.csv /data/raw` C. `hdfs dfs -put events.csv /data/raw/` D. `hdfs namenode -format events.csv`

Correct answer: C. `hdfs dfs -put events.csv /data/raw/`

Explanation: The `-put` command copies a local file into HDFS. Other useful commands include `-ls`, `-mkdir -p`, `-cat` and `-get`.

# Q10. After a NameNode restart, HDFS reports that safe mode is ON, and writes are rejected. What should the administrator do first?

A. Format the NameNode immediately. B. Delete all DataNode directories. C. Investigate safe-mode status, DataNode health and block-report conditions. D. Restart every application without checking logs.

Correct answer: C. Investigate safe mode and cluster health.

Explanation: HDFS safe mode is a protective state, often entered during startup while block reports arrive. Diagnose why it remains active before attempting corrective action. Formatting the NameNode can destroy filesystem metadata.

 Section 3: MapReduce

# Q11. In a Word Count MapReduce program, what does the Mapper typically emit for the word `data`?

A. `data → 1` B. `1 → data` C. `data → data` D. `data → 0`

Correct answer: A. `data → 1`

Explanation: The Mapper emits a key-value pair for each word. The framework groups values for the same key, and the Reducer calculates the total.

# Q12. What happens during the Shuffle and Sort stage of MapReduce?

A. All source files are deleted. B. Intermediate Mapper output is transferred and grouped by key for the appropriate Reducers. C. The entire dataset is loaded into one machine's memory. D. HDFS replication is permanently disabled.

Correct answer: B. Intermediate output is grouped and transferred by key.

Explanation: Shuffle and Sort organize intermediate key-value pairs so each Reducer receives the values associated with its keys. This network transfer can be expensive.

# Q13. A MapReduce job processes 1 TB of input, but one Reducer takes much longer than the others. What is a likely cause?

A. HDFS replication is always too high. B. The NameNode converts the input to JSON. C. Data skew sends disproportionately more data or work to one Reducer. D. Every Mapper is always executed twice.

Correct answer: C. Data skew.

Explanation: A dominant key can overload a Reducer. Investigate key distribution and partitioning; simply increasing the number of Reducers may not resolve a single hot key.

 Section 4: HBase

# Q14. A logistics company needs quick lookups and frequent updates to shipment records by unique shipment ID. Which technology is most suitable?

A. HBase B. Static HTML C. MapReduce alone D. A CSV file that must be scanned from beginning to end for every lookup

Correct answer: A. HBase

Explanation: HBase is a distributed, column-family-oriented NoSQL database built on HDFS. It supports row-key-based random reads and writes and is suitable for large, sparse datasets.

# Q15. Which HBase shell command retrieves a specific row using its row key?

A. `scan 'shipments'` B. `put 'shipments', 'S101', 'info:status', 'DELIVERED'` C. `get 'shipments', 'S101'` D. `create 'S101', 'shipments'`

Correct answer: C. `get 'shipments', 'S101'`

Explanation: `get` retrieves a specific row, `scan` reads multiple rows, `put` inserts or updates a cell, and `create` creates a table.

 Section 5: Hive and HiveQL

# Q16. Why do data engineers use Apache Hive?

A. To replace the Linux operating system B. To query and analyze large datasets using SQL-like HiveQL C. To configure network routers D. To replace every streaming system

Correct answer: B. Query and analyze large datasets using HiveQL.

Explanation: Hive provides a data warehouse layer over distributed storage and can execute queries using supported engines such as Tez or MapReduce, depending on configuration.

# Q17. Under typical Hive managed-table behavior, what happens when a managed table is dropped?

A. Metadata is removed, but the data must always remain. B. The table metadata and its managed data are normally removed. C. The HDFS NameNode is deleted. D. The Hive service is permanently shut down.

Correct answer: B. The metadata and managed data are normally removed.

Explanation: Hive controls the data lifecycle of managed tables. Dropping an external table normally removes its metadata but retains the underlying data. Exact behavior can depend on configuration and table properties.

# Q18. Application logs are stored in HDFS, and the team wants Hive to query them without taking ownership of the underlying files. Which table type is generally appropriate?

A. External table B. Managed table only C. Temporary table only D. HBase namespace

Correct answer: A. External table

Explanation: External tables are useful when files are managed independently of Hive or must remain available after the table definition is dropped.

# Q19. A Hive table contains 100 million records. Queries frequently filter by `event_date`. Which design can help reduce the data scanned?

A. Partition the table by `event_date`. B. Rename every column to the same name. C. Store the entire table in one local file. D. Remove the date values.

Correct answer: A. Partition by `event_date`.

Explanation: When partition pruning applies, Hive can skip partitions outside the requested date range. Excessive tiny partitions can hurt performance, so partition design must match query patterns.

# Q20. A Hive table is partitioned by date, but queries frequently filter by customer ID within each date. Which technique may help organize data within partitions?

A. Bucketing by customer ID B. Deleting the partition column C. Disabling all query optimizations D. Replacing every value with a constant

Correct answer: A. Bucketing by customer ID.

Explanation: Bucketing distributes records into a specified number of files based on a hash of selected columns. It can help certain joins and sampling operations, depending on the execution engine and table layout. Partitioning and bucketing solve different problems.

# Q21. A Hive query needs to convert customer names to uppercase using custom Java logic unavailable as a suitable built-in function. Which feature is appropriate?

A. HDFS replication B. YARN ResourceManager C. User-Defined Function (UDF) D. Kafka consumer offset

Correct answer: C. User-Defined Function (UDF)

Explanation: A UDF typically processes one input row and returns a value. A UDAF aggregates multiple rows, while a UDTF can produce multiple output rows from an input.

 Section 6: Data warehousing, ETL and Airflow

# Q22. A pipeline extracts records from a source, cleans invalid values, converts data types, and loads the results into a warehouse. What is this process called?

A. ETL B. DNS C. RAID D. CRUD only

Correct answer: A. ETL

Explanation: ETL means Extract, Transform, Load. In ELT, data is loaded first and transformed within the destination platform. Both approaches are used in modern data engineering.

# Q23. A retail analytics team needs to organize sales transactions for reporting. Which design most closely matches a typical star schema?

A. Store all data in one unstructured text file. B. Use a central fact table linked to dimension tables such as product, date and store. C. Store every transaction only in a Kafka topic. D. Use one dimension table without transaction measures or relationships.

Correct answer: B. A fact table linked to dimension tables.

Explanation: A fact table stores measurable events, such as sales quantity and revenue. Dimension tables describe the context, such as product, date, customer and store.

# Q24. In Apache Airflow, what is a DAG?

A. A distributed database table B. A Directed Acyclic Graph defining workflow tasks and dependencies C. A Kafka partition D. A Java compiler

Correct answer: B. A Directed Acyclic Graph.

Explanation: An Airflow DAG defines workflow structure and dependencies. Tasks can be implemented using operators, while the scheduler determines when eligible tasks should run.

# Q25. A daily Airflow pipeline must wait until `events.csv` appears before uploading it to HDFS. Which feature is designed for this requirement?

A. Sensor B. Reducer C. HDFS replication factor D. Spark broadcast variable

Correct answer: A. Sensor

Explanation: A sensor waits for a condition, such as file arrival. A robust workflow should also check timeouts, retries and whether the file is complete before processing it.

# Q26. An Airflow task loads transformed records into a database, fails after partially writing data, and is retried. Which design best reduces duplicate records?

A. Append every record again without checking. B. Disable task logs. C. Use stable keys and idempotent load logic, such as deduplication or merge/upsert operations. D. Delete the entire HDFS cluster before every retry.

Correct answer: C. Use idempotent load logic.

Explanation: Idempotency means repeated execution produces the same intended result instead of duplicate side effects. Airflow retries alone do not guarantee exactly-once writes to external systems.

 Section 7: Apache Spark, RDDs and optimization

# Q27. What is an RDD in Apache Spark?

A. A relational database server B. A Resilient Distributed Dataset that supports distributed parallel processing and fault recovery C. A Kafka topic configuration D. A Hive partition directory only

Correct answer: B. A Resilient Distributed Dataset.

Explanation: RDDs distribute data across partitions and support parallel transformations and actions. Lineage allows Spark to recompute lost partitions in many failure scenarios.

# Q28. Which statement correctly distinguishes a Spark transformation from an action?

A. `map()` is an action, and `count()` is a transformation. B. Both always write data to HDFS immediately. C. `filter()` is a transformation, and `count()` is an action. D. Transformations can only be applied to DataFrames.

Correct answer: C. `filter()` is a transformation, and `count()` is an action.

Explanation: Transformations define new datasets. Actions such as `count()`, `collect()` and `saveAsTextFile()` trigger execution. Spark commonly evaluates transformations lazily.

# Q29. Consider this PySpark code:

```
rdd = sc.parallelize([10, 20, 30, 40])result = rdd.filter(lambda x: x > 20).count()print(result)
```

What is the output?

A. 4 B. 3 C. 2 D. 1

Correct answer: C. 2

Explanation: The filter retains `30` and `40`. The `count()` action returns the number of retained elements, which is two.

# Q30. A Spark program reuses the same expensive intermediate DataFrame in five separate actions. Which approach may reduce repeated computation?

A. Cache or persist the DataFrame and reuse it when beneficial. B. Convert every DataFrame to a string. C. Restart the cluster before each action. D. Increase the number of output columns.

Correct answer: A. Cache or persist the DataFrame.

Explanation: Caching can reuse computed partitions instead of recomputing them for every action. It consumes storage resources, so cache data when the expected reuse justifies the cost.

# Q31. A Spark join combines a very large DataFrame with a small lookup DataFrame that fits in worker memory. Which technique may avoid shuffling the large DataFrame?

A. Broadcast join B. Collect the entire large DataFrame to the driver C. Convert all records into strings D. Disable the query optimizer

Correct answer: A. Broadcast join.

Explanation: Spark can distribute the small table to workers and join it locally with partitions of the large table. This is appropriate when the small side fits within available memory and the execution plan supports it.

# Q32. A Spark job spends most of its time transferring data between executors during a large join. Which operation is most directly associated with this cost?

A. A shuffle B. A Python variable assignment C. A local print statement D. A column alias change alone

Correct answer: A. A shuffle.

Explanation: A shuffle redistributes data between partitions. Large joins, aggregations and sorting operations can trigger shuffles. Examine the query plan, partitioning, skew and possible broadcast strategies to reduce unnecessary data movement.

# Q33. Which statement about RDDs, DataFrames and Datasets is correct?

A. RDDs always outperform DataFrames for every workload. B. DataFrames provide a schema-aware API that supports Spark SQL optimizations; typed Datasets are available in Scala and Java APIs. C. DataFrames cannot represent tabular data. D. PySpark provides the same strongly typed Dataset API as Scala.

Correct answer: B. DataFrames support structured query optimizations.

Explanation: RDDs offer lower-level flexibility. DataFrames enable query planning and optimization through Spark SQL. Typed Datasets are supported in Scala and Java, while PySpark primarily uses DataFrames rather than a typed Dataset API.

# Q34. A Spark job produces 10,000 tiny output files, making downstream processing inefficient. What is the best response?

A. Increase the number of partitions without measuring the effect. B. Remove the schema from every dataset. C. Review the partition count and use appropriate `repartition()` or `coalesce()` before writing. D. Convert all data into one record.

Correct answer: C. Review partitions and adjust before writing.

Explanation: Too many small files increase metadata overhead and downstream task costs. `coalesce()` can reduce partitions with limited redistribution, while `repartition()` redistributes data. The appropriate choice depends on data volume, skew and output requirements.

 Section 8: PySpark EDA and Spark SQL

# Q35. A dataset contains null values in `customer_age`. What should a data engineer do before calculating average age?

A. Convert every null to zero without checking its meaning. B. Examine the missing-data pattern and choose a suitable treatment, such as filtering, imputation or retaining nulls. C. Delete every record in the dataset. D. Rename the column and ignore data quality.

Correct answer: B. Investigate missing values and choose an appropriate treatment.

Explanation: Nulls may mean unknown, unavailable or inapplicable. Replacing them with zero can distort statistics. The strategy should match the business meaning and analytical objective.

# Q36. A column contains numeric values stored as strings, such as `"120"`, `"250"` and `"90"`. Why should it usually be converted to a numeric type before calculating an average?

A. Strings cannot be stored in Spark. B. Spark automatically interprets every string as a date. C. Numeric conversion enables valid arithmetic and aggregation, while invalid strings can be handled explicitly. D. Type conversion automatically removes duplicates.

Correct answer: C. Numeric conversion enables valid arithmetic.

Explanation: Correct data types are essential for meaningful calculations. A robust pipeline detects malformed values and checks for unexpected nulls after conversion.

# Q37. A Spark SQL query must assign a unique sequential number to employees within each department, with the highest salary first. Which approach is appropriate?

A. `ROW_NUMBER() OVER (PARTITION BY department ORDER BY salary DESC)` B. `COUNT(*) GROUP BY salary DESC` C. `DROP TABLE employees` D. `SELECT DISTINCT salary` only

Correct answer: A. Use `ROW_NUMBER()` with a window function.

Explanation: Window functions calculate results across related rows without collapsing each group into one row. `ROW_NUMBER()` assigns unique sequential numbers. For deterministic results when salaries tie, add a secondary ordering column, such as employee ID.

# Q38. A PySpark EDA report needs to identify the most frequent event type in a large dataset. Which approach is most appropriate?

A. Collect the entire raw dataset and process it on the driver. B. Group by event type, count occurrences, sort by count descending and retrieve a small result. C. Convert the dataset into an image. D. Delete duplicate event types before counting them.

Correct answer: B. Aggregate and sort in Spark.

Explanation: Distributed aggregation reduces the data before results are returned to the driver. Collecting a large raw dataset can exhaust driver memory. Retrieve only the top results when a full listing is unnecessary.

 Section 9: Kafka and streaming

# Q39. In a Kafka-based pipeline, what is the responsibility of a producer?

A. Publish records to Kafka topics B. Execute Hive queries only C. Manage the HDFS NameNode namespace D. Train every Spark MLlib model

Correct answer: A. Publish records to Kafka topics.

Explanation: Producers send records to topics. Brokers store topic partitions, and consumers read records. Kafka is commonly used for event ingestion and streaming data integration.

# Q40. A Kafka topic has six partitions, and a consumer group has three active consumers. Assuming balanced assignment and that all consumers can read all partitions, how many partitions can each consumer receive?

A. Six B. Three C. Two D. Zero

Correct answer: C. Two

Explanation: Within one consumer group, a partition is assigned to at most one consumer at a time. Six partitions can be balanced across three consumers, with two partitions per consumer.

# Q41. A Kafka consumer is processing events more slowly than producers are publishing them. The number of unprocessed records keeps increasing. What should the engineer investigate first?

A. Whether HDFS is automatically deleting Kafka topics B. Consumer lag, processing throughput, partition distribution and downstream bottlenecks C. Whether the NameNode has converted records into Hive tables D. Whether every message should be manually deleted

Correct answer: B. Investigate consumer lag and throughput.

Explanation: Consumer lag indicates how far behind a consumer is relative to the available topic data. Check processing time, consumer health, partition assignment, resource utilization and sink performance before deciding whether to scale consumers or optimize processing.

# Q42. A streaming application receives events late because devices have unreliable network connections. Which Spark Structured Streaming feature can help manage late-arriving events in event-time window aggregations?

A. Watermarks B. HDFS replication factor C. Hive table ownership D. Python list indexing

Correct answer: A. Watermarks

Explanation: A watermark defines how long a streaming query is prepared to wait for late event-time data while managing aggregation state. Its behavior depends on the query, output mode and stateful operation; it does not guarantee that every arbitrarily late event will be included.

# Q43. What is Apache Kafka Connect primarily used for?

A. Connecting data sources and sinks to Kafka through reusable connectors B. Replacing the JVM C. Executing every Spark SQL query D. Formatting HDFS block metadata

Correct answer: A. Connecting data sources and sinks to Kafka.

Explanation: Source connectors bring external data into Kafka; sink connectors export Kafka data to external systems. Kafka Connect can run in standalone or distributed mode.

 Section 10: Spark MLlib, cloud and end-to-end scenarios

# Q44. A data science team wants to predict whether a railway trip will be delayed by more than 15 minutes. The target contains `YES` or `NO`. Which type of machine learning problem is this?

A. Clustering B. Classification C. Association rule mining only D. Dimensionality reduction only

Correct answer: B. Classification

Explanation: Classification predicts a discrete category. If the target were the actual delay duration in minutes, the task would instead be a regression problem.

# Q45. A Spark MLlib model achieves 99% accuracy on training data but only 65% accuracy on unseen test data. What is the most likely concern?

A. The model may be overfitting the training data. B. HDFS replication is automatically disabled. C. Kafka has no partitions. D. The Spark DataFrame must contain no columns.

Correct answer: A. Overfitting.

Explanation: Overfitting occurs when a model learns patterns specific to training data that do not generalize. Investigate data leakage, model complexity, train/test splitting and regularization. For imbalanced classes, also examine precision, recall, F1-score and the confusion matrix.

# Q46. A Spark workload runs on a cloud cluster, and data volume increases substantially during business hours. Which approach can help manage changing demand?

A. Allocate the maximum number of machines permanently without measuring usage. B. Disable monitoring and logging. C. Use cluster autoscaling where supported and monitor workload performance and cost. D. Move all processing into the Airflow scheduler process.

Correct answer: C. Use autoscaling and monitor cost.

Explanation: Autoscaling can add or remove compute resources as workload demand changes. Engineers must also consider startup delays, shuffle-heavy stages, minimum and maximum cluster sizes, and storage costs.

# Q47. A Spark job reads data from a relational database using JDBC. The source database slows down because the job opens too many simultaneous connections. What is the best response?

A. Increase JDBC parallelism without checking the database. B. Tune partitioned reads and connection counts to balance throughput with database capacity. C. Read the entire database into one Python list on the driver. D. Disable database monitoring.

Correct answer: B. Tune parallelism and connection counts.

Explanation: Spark can read and write relational databases through JDBC. Excessive parallelism can overload the source. Select suitable partition bounds, connection counts and batch sizes while monitoring database capacity.

# Q48. A sales analytics team wants to compare monthly revenue across stores and product categories. Which SQL operation is most appropriate for calculating the grouped revenue?

A. `GROUP BY` with `SUM(revenue)` B. `DROP TABLE` C. `DELETE FROM sales` D. `ORDER BY` without an aggregation

Correct answer: A. `GROUP BY` with `SUM(revenue)`.

Explanation: `GROUP BY` groups records by selected dimensions, while `SUM()` aggregates revenue within each group. `ORDER BY` can then sort the resulting totals.

# Q49. An Airflow pipeline works on a developer's laptop but fails in a managed cloud Airflow environment. What is the best first troubleshooting approach?

A. Assume the cloud environment has the same packages, paths and credentials as the laptop. B. Check dependency installation, connection configuration, permissions, environment variables, network access and storage paths. C. Delete the DAG and recreate the entire cluster immediately. D. Disable all task logs and retries.

Correct answer: B. Verify environment and connectivity differences.

Explanation: Managed Airflow environments may have different installed libraries, execution identities, secrets, network rules and filesystem layouts. Inspect task logs and environment configuration before changing infrastructure.

# Q50. A company receives daily JSON files and continuous order events. It needs historical reports and near-real-time analytics. Which architecture best integrates the syllabus technologies?

A. Use Hive alone for every ingestion, orchestration, streaming and machine learning requirement. B. Use Kafka alone for orchestration, batch transformations and every historical query. C. Use Airflow to orchestrate batch workflows, HDFS or cloud storage for data, Spark for transformations and analytics, Hive or Spark SQL for queries, and Kafka with Structured Streaming for real-time events. D. Use a local text editor and manually combine all files every day.

Correct answer: C. Integrate the technologies according to their responsibilities.

Explanation: This architecture separates orchestration, storage, processing, querying and streaming.

- Airflow: schedules and coordinates tasks.
- HDFS or cloud storage: stores raw and processed datasets.
- Spark: performs scalable transformations, analytics and machine learning.
- Hive / Spark SQL: supports SQL-based analytical queries.
- Kafka: ingests and transports continuous events.
- Spark Structured Streaming: processes event streams.
- Monitoring and validation: detect failures, bad records, duplicates and data quality problems.

Production systems also need access control, schema evolution, checkpointing, idempotent writes, recovery procedures, observability and cost management.

53.  A Spark job repeatedly scans the same large source dataset for three independent reports. The source is expensive to read and transform. Which optimization should you consider?

A) Recompute the entire source for every report B) Cache or persist the shared intermediate DataFrame and reuse it across the reports C) Convert every DataFrame to a Python list D) Call `collect()` on the source

Answer: B. Persisting reusable intermediate data can avoid repeated computation. Confirm that memory and storage costs are justified, and unpersist the data when it is no longer needed.

54.  A customer table contains multiple updates per `user_id`. You must retain the latest complete record using `updated_at`. Which SQL approach is correct?

A) Group by `user_id` and select every non-aggregated column without a defined rule B) Apply `ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY updated_at DESC)` and retain row number 1 C) Sort the entire table and keep the first row globally D) Apply `DISTINCT` to every column

Answer: B. A window function selects one latest row per user. Add a deterministic tie-breaker if multiple records share the same timestamp.

55.  A product team wants to calculate each product's day-over-day sales change. Which SQL function is most appropriate?

A) `RANK()` B) `LAG(sales) OVER (PARTITION BY product_id ORDER BY sale_date)` C) `COUNT(*)` D) `NTILE(4)`

Answer: B. `LAG()` retrieves the previous row's sales within each product's ordered history. Subtract the previous value from the current value to calculate the change.

 Section 9: Kafka Reliability and Structured Streaming

56.  A Kafka producer must avoid acknowledging a write until the replicated record has been safely accepted by the required in-sync replicas. Which configuration is most appropriate for strong durability?

A) `acks=0` and replication factor 1 B) `acks=1` with no consideration of replica availability C) `acks=all`, a suitable replication factor, and an appropriate `min.insync.replicas` setting D) Disable replication and retries

Answer: C. `acks=all` waits for the current in-sync replicas to acknowledge the write. A suitable `min.insync.replicas` setting controls how many in-sync replicas must be available for writes to succeed. Producer idempotence can further reduce duplicate writes caused by retries.

57.  A Kafka consumer crashes after processing a message but before committing its offset. The message is processed again after restart. How should the downstream system handle this safely?

A) Disable all offset commits permanently B) Make the sink idempotent, using upserts or deduplication based on a unique event identifier C) Reduce the number of Kafka brokers D) Increase the replication factor only

Answer: B. At-least-once processing can produce duplicate deliveries. An idempotent sink prevents repeated processing from creating duplicate business results.

58.  A Spark Structured Streaming job calculates five-minute event-time counts. Events may arrive up to ten minutes late, and aggregation state grows continuously. What should you do?

A) Call `collect()` in every micro-batch B) Define an appropriate watermark, such as `withWatermark("event_time", "10 minutes")`, and use supported window aggregation semantics C) Remove event timestamps D) Increase the trigger interval to several days

Answer: B. Watermarks allow Spark to finalize eligible event-time windows and clean up old state. Events arriving beyond the watermark may be excluded from stateful results, depending on the operation.

59.  A Spark Structured Streaming application restarts after a failure and needs to recover its processed offsets and state. What is essential?

A) A larger driver only B) A stable `checkpointLocation` on reliable storage C) A Hive database with no checkpoint D) A larger Kafka message size

Answer: B. A checkpoint records streaming progress and state needed for recovery. The checkpoint location must remain stable across restarts of the same query.

 Section 10: Hive and HDFS Operations

60.  A Hive table uses transactional ACID storage. A large number of updates and deletes have produced many delta files, and query performance has deteriorated. What should you investigate?

A) Increase HDFS replication to 10 B) Hive ACID compaction and transaction-related configuration C) Format the NameNode D) Drop the database without a backup

Answer: B. Compaction consolidates transactional files, reducing the overhead of reading many delta files. The exact procedure depends on the Hive version and table configuration.

61.  An upstream process creates new date-partition directories directly under an external Hive table's HDFS location. The new records are not visible in queries. What should you do?

A) Drop the entire database B) Register the partitions using `MSCK REPAIR TABLE table_name` or suitable `ALTER TABLE ... ADD PARTITION` statements C) Delete all HDFS files D) Restart every DataNode

Answer: B. Hive needs partition metadata to discover externally created partition directories when they have not been registered automatically.

62.  After a NameNode restart, users can read HDFS files but cannot write new ones. The NameNode web interface reports that safe mode is enabled. What does this mean?

A) The cluster is permanently corrupted B) The NameNode is protecting the file system while it waits for sufficient block reports and safe-mode conditions C) YARN has necessarily crashed D) All HDFS blocks have been deleted

Answer: B. Check DataNode health, block reports, and safe-mode status. Leave safe mode only after understanding why it remains enabled.

63.  Five new DataNodes have been added to a cluster, but old DataNodes are 90% full while the new nodes are nearly empty. Which utility can help redistribute blocks?

A) `hdfs balancer` B) `hdfs fsck -delete` C) `hdfs dfs -expunge` D) `hdfs namenode -format`

Answer: A. The HDFS Balancer redistributes block replicas to improve storage utilization. Never format a live NameNode as a balancing solution.

64.  An analytics platform changes a Parquet dataset by adding a new nullable column. Some older files do not contain that column. What should the data engineer do?

A) Assume every reader will always infer the same schema automatically B) Manage schema evolution explicitly and verify the reader's schema-merging and compatibility behavior C) Delete every older data file D) Convert all records to separate JSON files

Answer: B. Schema evolution depends on the table format, catalog, reader, and configuration. Validate compatibility so older files can be queried correctly alongside newer files.

 Section 11: Airflow, Data Quality and Warehousing

65.  A file arrives at an unpredictable time between 2 AM and 6 AM. An Airflow sensor occupies a worker slot for hours, starving other tasks. What is the best solution?

A) Use a six-hour `sleep()` in a Python task B) Use sensor `reschedule` mode or a compatible deferrable operator C) Remove the sensor and assume the file exists D) Set retries to 1,000

Answer: B. Reschedule mode releases the worker slot between checks; deferrable operators can suspend work and use the triggerer for asynchronous waiting.

66.  A developer has hard-coded a database password in a DAG file committed to Git. What is the correct practice?

A) Keep it because the repository is private B) Store credentials in Airflow Connections or an approved secrets backend C) Put the password in a code comment D) Base64-encode the password in the DAG

Answer: B. Secrets should be managed securely and referenced through approved connection mechanisms. Base64 encoding does not provide encryption.

67.  An incoming order batch contains 3% of records with a null `customer_id`. The business needs clean reports but does not want the invalid records lost. What is the best design?

A) Silently discard the entire batch B) Load valid records into the main table, route invalid records to a quarantine table, and alert the appropriate team C) Generate random customer IDs for invalid records D) Ignore the problem because only 3% of records are affected

Answer: B. Quarantine preserves evidence for investigation while protecting downstream reports from invalid data.

68.  A customer changes their address, but the business needs historical reports to show the address that was valid when each order was placed. Which data warehouse technique fits best?

A) Slowly Changing Dimension Type 1, which overwrites the old value B) Slowly Changing Dimension Type 2, which retains historical versions with effective dates or current flags C) Delete every historical order D) Store only the customer's latest address

Answer: B. SCD Type 2 preserves history. Fact records must be associated with the appropriate dimension version for historical reporting.

 Section 12: Data Science, Machine Learning and Cloud

69.  A fraud detection model achieves 99.5% accuracy on a dataset where only 0.5% of transactions are fraudulent, but it fails to flag any fraud. What is the main issue?

A) The model is perfect B) Class imbalance makes accuracy misleading; evaluate precision, recall, F1 and PR-AUC, and consider class weights or resampling C) Accuracy is the only useful classification metric D) The dataset cannot be used for machine learning

Answer: B. Predicting every transaction as legitimate can produce 99.5% accuracy in this example while detecting no fraud. Select metrics based on business costs and the precision-recall trade-off.

70.  A nightly Spark ETL job requires two hours of compute, but the team leaves a large EMR or Databricks cluster running 24/7. What is the best cost optimization?

A) Add more nodes and keep them running B) Use job or ephemeral clusters, automatic termination, appropriate autoscaling, and spot capacity where interruption is acceptable C) Disable logging and data replication indiscriminately D) Move all processing to one machine regardless of data volume

Answer: B. Matching compute capacity to the workload reduces idle costs. Spot instances can lower costs further, but interruption handling and data durability must be considered.
