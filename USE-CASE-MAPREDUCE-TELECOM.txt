package com.company.telecom;

import .io.IOException;

import org.apache.hadoop.io.IntWritable;
import org.apache.hadoop.io.;
import org.apache.hadoop.mapreduce.Mapper;

public class NetworkErrorMapper
        extends Mapper<Object, , , IntWritable> {

    private final static IntWritable one = new IntWritable(1);
    private  errorCode = new ();

    @Override
    public void map(Object key,  value, Con con)
            throws IOException, InterruptedException {

        String[] fields = value.toString().split(",");

        if (fields.length == 3) {

            String error = fields[2].trim();

            errorCode.set(error);

            con.write(errorCode, one);
        }
    }
}

# PART 10 — Create Reducer

// Step 11 — Create Reducer


nano src/com/company/telecom/NetworkErrorReducer.


Enter:


package com.company.telecom;

import .io.IOException;

import org.apache.hadoop.io.IntWritable;
import org.apache.hadoop.io.;
import org.apache.hadoop.mapreduce.Reducer;

public class NetworkErrorReducer
        extends Reducer<, IntWritable, , IntWritable> {

    private IntWritable result = new IntWritable();

    @Override
    public void reduce( key, Iterable<IntWritable> values,
                       Con con)
            throws IOException, InterruptedException {

        int sum = 0;

        for (IntWritable value : values) {
            sum += value.get();
        }

        result.set(sum);

        con.write(key, result);
    }
}

# PART 11 — Understand Shuffle and Sort

Mapper produces:


ERROR_500    1
ERROR_404    1

ERROR_503    1
ERROR_404    1
ERROR_500    1
ERROR_503    1


Hadoop's Shuffle and Sort stage groups identical keys:


ERROR_404 → [1,1]
ERROR_500 → [1,1,1]
ERROR_503 → [1,1]


The Reducer receives these grouped values.

# PART 12 — Create Driver

The Driver configures the MapReduce job.

It tells Hadoop:

* Mapper class
* Reducer class
* Input location
* Output location
* Mapper output key/value types
* Reducer output key/value types

// Step 12 — Create Driver


nano src/com/company/telecom/TelecomErrorDriver.


Enter:


package com.company.telecom;

import org.apache.hadoop.conf.Configuration;
import org.apache.hadoop.fs.Path;
import org.apache.hadoop.io.IntWritable;
import org.apache.hadoop.io.;
import org.apache.hadoop.mapreduce.Job;
import org.apache.hadoop.mapreduce.lib.input.FileInputFormat;
import org.apache.hadoop.mapreduce.lib.output.FileOutputFormat;

public class TelecomErrorDriver {

    public static void main(String[] args) throws Exception {

        if (args.length != 2) {
            System.err.println(
                "Usage: TelecomErrorDriver <input> <output>"
            );
            System.exit(2);
        }

        Configuration conf = new Configuration();

        Job job = Job.getInstance(conf,
                "Telecom Network Error Analysis");

        job.setJarByClass(TelecomErrorDriver.class);

        job.setMapperClass(NetworkErrorMapper.class);
        job.setReducerClass(NetworkErrorReducer.class);

        job.setMapOutputKeyClass(.class);
        job.setMapOutputValueClass(IntWritable.class);

        job.setOutputKeyClass(.class);
        job.setOutputValueClass(IntWritable.class);

        FileInputFormat.addInputPath(job, new Path(args[0]));
        FileOutputFormat.setOutputPath(job, new Path(args[1]));

        System.exit(job.waitForCompletion(true) ? 0 : 1);
    }
}

# PART 31 — Important Interview Explanation

// Question: What does the Mapper do?

Answer:

The Mapper reads each network log record, extracts the error code, and emits the error code with a value of `1`.

Example:


CELL01,2026-09-20,ERROR_500


becomes:


ERROR_500    1


---

// Question: What does Shuffle and Sort do?

Answer:

Shuffle and Sort groups all values belonging to the same error code.


ERROR_500 → [1,1,1]


---

// Question: What does the Reducer do?

Answer:

The Reducer adds the values for each error code.


ERROR_500 → 1 + 1 + 1 = 3


---

// Question: Why does the Mapper emit `1`?

Because every input record represents one occurrence of an error.

Therefore:


One error occurrence → 1


Three occurrences:


1 + 1 + 1 = 3

# PART 33 — Banking vs Telecom

This is a useful way to teach students that the MapReduce pattern stays the same while the business data changes.

| Banking                   | Telecom                       |

| Transaction record        | Network log                   |
| `TXN001,ATM,5000`         | `CELL01,2026-09-20,ERROR_500` |
| Extract `ATM`             | Extract `ERROR_500`           |
| `ATM → 1`                 | `ERROR_500 → 1`               |
| Group by transaction type | Group by error code           |
| Count transactions        | Count errors                  |
| `ATM → 3`                 | `ERROR_500 → 3`               |

The key difference is simply:


Banking:
Mapper extracts field[1]

Telecom:
Mapper extracts field[2]


The Reducer logic remains the same:


int sum = 0;

for (IntWritable value : values) {
    sum += value.get();
}


> MapReduce is a reusable processing pattern. The business field used as the key changes according to the analytics requirement, while the Map → Shuffle → Reduce architecture remains the same.
