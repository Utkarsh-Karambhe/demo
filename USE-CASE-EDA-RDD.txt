# 6. Create the PySpark Program

Create:

bash
nano telecom_eda_rdd.py


Paste this complete program:

python
from pyspark.sql import SparkSession
from pyspark.sql.functions import avg, count, col


# 1. Initialize Spark


spark = SparkSession.builder \
    .appName("TelecomCustomerAnalytics") \
    .master("local[*]") \
    .getOrCreate()

print("Spark Started Successfully")



# 2. Load CSV Dataset


df = spark.read.csv(
    "data/telecom_customers.csv",
    header=True,
    inferSchema=True
)

print("\nOriginal Data:")
df.show()



# 3. Display Schema


print("\nOriginal Schema:")
df.printSchema()



# 4. Handle NULL Values


df_clean = df.fillna({
    "age": 0,
    "monthly_bill": 0.0,
    "tenure": 0
})

print("\nData After Handling NULL Values:")
df_clean.show()



# 5. Type Conversion


df_clean = df_clean \
    .withColumn("age", col("age").cast("integer")) \
    .withColumn("monthly_bill", col("monthly_bill").cast("double")) \
    .withColumn("tenure", col("tenure").cast("integer"))

print("\nSchema After Type Conversion:")
df_clean.printSchema()



# 6. EDA - Total Customers


total_customers = df_clean.count()

print("\nTotal Customers:")
print(total_customers)



# 7. EDA - Average Monthly Bill


print("\nAverage Monthly Bill:")

df_clean.select(
    avg("monthly_bill").alias("average_monthly_bill")
).show()



# 8. EDA - Customers By City


print("\nCustomers By City:")

df_clean.groupBy("city") \
    .agg(count("*").alias("customer_count")) \
    .orderBy(col("customer_count").desc()) \
    .show()



# 9. EDA - High Bill Customers


print("\nCustomers With Monthly Bill Greater Than 700:")

df_clean.filter(
    col("monthly_bill") > 700
).show()



# 10. EDA - Average Bill By Plan


print("\nAverage Monthly Bill By Plan:")

df_clean.groupBy("plan") \
    .agg(avg("monthly_bill").alias("average_bill")) \
    .show()



# 11. RDD Creation


print("\nRDD Demonstration:")

rdd = spark.sparkContext.parallelize(
    [100, 200, 300, 400, 500]
)

print("Original RDD:")
print(rdd.collect())



# 12. RDD Transformation


rdd_doubled = rdd.map(
    lambda x: x * 2
)

print("RDD After map Transformation:")
print(rdd_doubled.collect())



# 13. RDD Filter Transformation


rdd_filtered = rdd.filter(
    lambda x: x > 250
)

print("RDD After filter Transformation:")
print(rdd_filtered.collect())



# 14. RDD Action


print("RDD Count:")
print(rdd_filtered.count())



# 15. Cache Optimization


df_clean.cache()

print("\nFirst Action After Cache:")
start_count = df_clean.count()

print("Customer Count:")
print(start_count)


print("\nSecond Action After Cache:")
average_result = df_clean.select(
    avg("monthly_bill")
).collect()

print(average_result)



# 16. Stop Spark


spark.stop()

print("\nSpark Application Completed")

# 16. Transformation vs Action

This is important for your students.

//# Transformation

Transformation creates another RDD/DataFrame.

Examples:

text
map()
filter()
flatMap()
groupByKey()
reduceByKey()


Spark does not immediately execute the transformation.

//# Action

Action actually triggers execution.

Examples:

text
count()
collect()
first()
reduce()


Simple flow:

text
RDD
 |
 | map()
 v
RDD
 |
 | filter()
 v
RDD
 |
 | count()
 v
RESULT




# 17. Optimization: Caching

The optimization technique we use is:

> Caching

We write:

python
df_clean.cache()


Why?

Suppose we use the same DataFrame multiple times:

text
df_clean
   |
   +- count()
   |
   +- average()
   |
   +- groupBy()


Without caching, Spark may need to recompute the DataFrame.

With:

python
df_clean.cache()


Spark keeps the computed data in memory after it is first used.

So subsequent operations can reuse it.

Simple idea:

text
Without cache:

Data → Process → Count
Data → Process → Average
Data → Process → GroupBy


With cache:

Data → Process → CACHE
                     |
              +++
              |      |      |
            Count  Average GroupBy

# 19. RDD vs DataFrame

Give students this simple table:

| RDD                             | DataFrame                             

| Low-level API                   | Higher-level API                      |
| Works with objects              | Works with rows/columns               |
| Less optimized                  | Highly optimized                      |
| More coding                     | Less coding                           |
| `map()` / `filter()`            | `select()` / `filter()` / `groupBy()` |
| Useful for low-level processing | Best for structured data              |

For our telecom dataset:

text
CSV
 ↓
DataFrame


is the better choice because the data has columns:

text

name
age
city
monthly_bill
tenure

# 26. One-Line Explanation for Each Concept

Spark: Distributed processing engine.

SparkSession: Entry point for DataFrame-based Spark programs.

DataFrame: Structured data organized into rows and columns.

RDD: Distributed collection of data.

Transformation: Operation that creates new data from existing data.

Action: Operation that produces a result and triggers execution.

EDA: Exploring data to understand patterns and statistics.

Preprocessing: Cleaning and preparing data before analysis.

Cache: Keeps computed data available for reuse to reduce recomputation.

Partition: A piece of distributed data processed by Spark.

Shuffle: Movement of data between partitions, commonly during operations such as `groupBy` and joins.

Broadcast variable: Sends a small read-only dataset efficiently to executors.
